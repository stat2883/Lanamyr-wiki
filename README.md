# Lanamyr World Bible

The working lore repository for the Lanamyr fantasy setting.

## Structure

- `bible/` — the world bible, split across 8 topic files:
  1. Maps Reference
  2. Overview & Cosmology
  3. Geography
  4. Races
  5. Kingdoms & History
  6. Characters & Items
  7. Stories & Outlines
  8. Open Questions
- `bible/maps/` — reference map images (continents, features, islands, biomes, temperature, precipitation, race origins, and per-epoch maps)
- `archive/` — browsable snapshots of past bible versions, one folder per version (`v001`, `v002`, ...). Text files only; maps are not duplicated into snapshots.
- `SESSION_INSTRUCTIONS.md` — authoritative workflow for working sessions on the bible

Confirmed lore is locked in. Tentative lore is flagged as such within the files and remains subject to change.
