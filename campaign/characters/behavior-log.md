# PC Behaviour Log

A running, dated record of **what the player characters actually did** —
observed actions, not declared traits. Covers Sharii, Alinar, and (from her
arrival before session 3) Ignis.

**Why this file exists.** The character sheets list personality, ideals, bonds
and flaws as *undeveloped*, deliberately, so they can emerge through play. This
file is the compromise: it preserves the pattern across sessions without
boxing either character in. A future session reads evidence rather than
re-deriving a personality from twelve pages of event logs, and the DM reaches
for the same answer the players would.

**Rules for this file:**
- Record **behaviour with a date and a session number**. Never record a trait.
  Not *"Sharii is empathetic"* — instead *"S2: asked Mya's opinion first and in
  public."*
- Everything here is **reversible**. If a character turns out to be someone
  else, an entry simply becomes a thing he used to do.
- Record **what NPCs observed**, where it matters, since that is what drives
  how they respond later.
- Append only. Newest at the bottom of each character's section.
