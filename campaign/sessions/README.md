# Session Logs

One numbered file per session: `001-<short-title>.md`, `002-...`, and so on.

Each session file should record:
- In-world date range covered
- Where the party went and what they did
- Combat encounters and outcomes
- NPCs met or changed
- XP and loot awarded
- Any unresolved cliffhanger carried into the next session
- Anything established that belongs in `reference/lore-deltas.md`

`campaign-status.md` must be updated to match at the end of every session. That
file, not this directory, is the resume point.
